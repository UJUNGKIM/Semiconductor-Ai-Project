# 취약 클래스 개선 실험 프로토콜

## 목적

Scratch, Loc, Edge-Loc가 none으로 오분류되는 현상을 줄이되 전체 분류 성능과 none 재현율을 유지합니다.

## 비교 후보

1. baseline: 기존 cross-entropy와 sqrt-balanced sampling 재현
2. weak_defect_thinning: train의 세 취약 클래스에만 결함 die 3~12% thinning 적용
3. weak_thinning_hard_negative: thinning과 함께 train의 none 중 결함 die 비율 상위 10%를 2배 샘플링

thinning은 결함 채널만 줄이며 활성 die 마스크는 바꾸지 않습니다. 결함 die를 최소 1개 이상 유지합니다.

## 선택 규칙

- 1차 목표: Validation의 Scratch·Loc·Edge-Loc 평균 재현율
- 전체 macro-F1: baseline보다 0.005를 초과해 낮아지면 탈락
- none 재현율: baseline보다 0.002를 초과해 낮아지면 탈락
- 동률이면 Validation macro-F1이 높은 후보 선택

## 데이터 누수 방지

- 증강과 hard-negative 선정은 train에서만 수행
- 후보 선택은 validation만 사용
- Test 추론 및 성능 계산은 수행하지 않음
- 선택 후보는 여러 seed로 재현한 뒤에만 최종 Test 평가 대상으로 검토
