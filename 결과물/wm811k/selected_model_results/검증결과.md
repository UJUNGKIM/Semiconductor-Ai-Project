## 불확실성 검토 정책

`uncertainty_policy.json`은 validation 예측의 negative log-likelihood만 사용해 온도
`1.04717171`을 추정했다. 같은 validation에서 자동 분류 목표 비율을 90%로 두어 보정
최대 확률 `0.97499829`를 검토 임계값으로 고정했다. test는 임계값 선택에 사용하지
않고 고정 정책 평가에만 사용했다.

- test 자동 분류: 22,335 / 24,705개 (90.41%)
- 자동 분류 구간 정확도: 99.84%
- 전문가 검토 대상: 2,370개 (9.59%)
- 전체 오류 561개 중 검토 대상으로 포착: 525개 (93.58%)

이 정책은 낮은 신뢰도 표본을 검토 대상으로 보내는 연구용 안전장치다. 자동 분류
구간 정확도는 신규 lot나 다른 장비에서도 그대로 유지된다고 볼 수 없다.

## Test 사후 오분류 분석

`error_analysis.json`은 모델과 검토 정책을 모두 고정한 뒤 test 예측을 분석한 결과다.
모델 선택이나 신뢰도 임계값 결정에는 사용하지 않았다.

- 전체 오분류: 561 / 24,705개
- 가장 많은 혼동: `Edge-Loc → none` 92건 (전체 오류의 16.40%)
- 두 번째 혼동: `Loc → none` 82건 (전체 오류의 14.62%)
- 결함 클래스 최저 재현율: `Scratch` 71.76% (48 / 170개 오분류)
- `Near-full`: test 표본이 21개뿐이므로 재현율 90.48%를 안정적인 일반화 수치로
  해석할 수 없다.

클래스별 검토 정책은 오류 포착률 90% 이상을 대체로 유지했지만, 이는 같은 WM-811K
분포 안에서의 사후 결과다. 특히 `Edge-Loc`, `Loc`, `Scratch`는 후속 데이터 확보와
오분류 형태 점검의 우선순위다.
